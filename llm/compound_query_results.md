## 4. Summary in Plain Language  

The Dell Inspiron 14 7472 is a 14‑inch “7000‑series” laptop released in 2017‑2018. It offers 8th‑generation Intel Core i5 or i7 processors, optional NVIDIA MX150 graphics, up to 16 GB of DDR4 RAM, and flexible storage options (SSD, HDD, or both). The screen is a full‑HD IPS panel, and the machine includes a full set of modern ports (USB‑C, HDMI, SD‑card reader). It ships with Windows 10 (upgradeable to Windows 11) and provides around 8‑10 hours of battery life.
