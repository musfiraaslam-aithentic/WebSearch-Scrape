# Query: t3a.medium Amazon

The t3a.medium is an Amazon EC2 instance type designed for burstable general-purpose workloads. It belongs to the T3a instance family, which offers a balance of compute, memory, and network resources at a cost-effective price. T3a instances are powered by AMD EPYC 7000 series processors.

Here are the specifications for the t3a.medium instance:

### Specifications for t3a.medium Amazon EC2 Instance

*   **Instance Family**: General Purpose, Burstable Performance
*   **vCPUs**: 2
*   **Memory (GiB)**: 4 GiB
*   **Processor**: AMD EPYC 7000 series (specifically AMD EPYC 7571)
*   **Clock Speed**: 2.5 GHz all-core turbo
*   **CPU Architecture**: x86_64
*   **Network Performance**: Up to 5 Gigabit
*   **EBS Optimized**: Default
*   **EBS Throughput (Max)**: Up to 2085 Mbps
*   **Baseline Performance**: Provides a baseline level of CPU performance with the ability to burst higher CPU usage
*   **CPU Credits**: Accumulates CPU credits when operating below the baseline and uses them to burst to higher performance. Can operate in "Unlimited" mode.
*   **Hypervisor**: Powered by the AWS Nitro System
*   **Instance Storage**: EBS Only
*   **Enhanced Networking**: Yes
*   **Typical Use Cases**: Microservices, low-latency interactive applications, small to medium databases, virtual desktops, development environments, code repositories, and critical business applications.
