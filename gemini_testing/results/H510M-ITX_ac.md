# Query: H510M-ITX/ac

The ASRock H510M-ITX/ac is a Mini-ITX motherboard designed to support Intel's 10th and 11th Generation Core Processors. It features the Intel H510 chipset and offers a compact solution for small form factor builds, including integrated Wi-Fi and Bluetooth capabilities.

### Specifications

Here are the detailed specifications for the ASRock H510M-ITX/ac motherboard:

*   **Processor Support:**
    *   Supports 10th Gen Intel Core Processors (LGA1200)
    *   Supports 11th Gen Intel Core Processors (LGA1200)
    *   6 Phase Dr.MOS Power Design
*   **Chipset:**
    *   Intel H510
*   **Memory:**
    *   Dual Channel DDR4 Memory Technology
    *   Supports DDR4 3200MHz (11th Gen Intel Core i9/i7/i5), 2933MHz (10th Gen Intel Core i9/i7) and 2666MHz (11th Gen Intel Core i3/Pentium/Celeron, 10th Gen Intel Core i5/i3/Pentium/Celeron)
    *   Maximum memory capacity of 64GB
    *   Memory Slots: 2 x DDR4 DIMM slots
*   **Expansion Slots:**
    *   1 x PCIe 4.0 x16 slot (PCIe Gen4 is only supported with 11th Gen Intel Core Processors)
*   **Graphics:**
    *   Graphics Output Options: HDMI, DisplayPort
    *   HDMI supports 4K at 60Hz
*   **Audio:**
    *   7.1 CH HD Audio (Realtek ALC897 Audio Codec)
*   **Storage:**
    *   4 x SATA3 6.0 Gb/s ports
    *   1 x Ultra M.2 (PCIe Gen3 x4 & SATA3) interface, supporting up to 32Gb/s (M2_1) (If a SATA-type M.2 device is used, SATA3_0 will be disabled)
*   **USB:**
    *   4 x USB 3.2 Gen1 (2 x Rear, 2 x Front)
    *   4 x USB 2.0 (2 x Rear, 2 x Front)
*   **Networking:**
    *   **LAN:** Intel Gigabit LAN
    *   **Wireless:** Intel 802.11ac WiFi (2.4G / 5G WiFi) + Bluetooth 4.2
*   **Form Factor:**
    *   Mini-ITX
*   **Unique Features:**
    *   ASRock Polychrome SYNC (RGB lighting support)
    *   Clever Access Memory
    *   Base Frequency Boost (BFB) Technology
    *   High-Density Glass Fabric PCB
    *   Water Pump Header
