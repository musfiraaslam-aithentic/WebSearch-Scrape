# Query: H610M H V2 DDR4 GIGABYTE

The GIGABYTE H610M H V2 DDR4 is a micro-ATX motherboard designed to support Intel's 12th, 13th, and 14th generation processors. It features a robust power design and offers essential connectivity for a modern PC build, utilizing DDR4 memory.

Here are the specifications for the GIGABYTE H610M H V2 DDR4 motherboard:

### Specifications

*   **Motherboard Model:** GIGABYTE H610M H V2 DDR4 (rev. 1.0)
*   **Form Factor:** Micro ATX
*   **CPU Support:**
    *   Supports 14th, 13th, and 12th Generation Intel® Core™ Processors
    *   LGA1700 Socket
*   **Chipset:** Intel® H610 Express Chipset
*   **Memory:**
    *   2 x DDR4 DIMM sockets
    *   Supports up to 64 GB of system memory (32 GB single DIMM capacity)
    *   Dual Channel Memory Architecture
    *   Support for DDR4 3200/3000/2933/2666/2400/2133 MT/s memory modules
    *   Supports ECC Un-buffered DIMM 1Rx8/2Rx8 memory modules (operating in non-ECC mode)
    *   Supports non-ECC Un-buffered DIMM 1Rx8/2Rx8/1Rx16 memory modules
    *   Supports Extreme Memory Profile (XMP) memory modules
*   **Onboard Graphics:**
    *   Integrated Graphics Processor - Intel® HD Graphics support
    *   1 x D-Sub port, supporting a maximum resolution of 1920x1200@60 Hz
    *   1 x HDMI port, supporting a maximum resolution of 4096x2160@60 Hz (HDMI 2.1 and HDCP 2.3 support)
*   **Audio:**
    *   Realtek® Audio CODEC
    *   High Definition Audio
    *   2/4/5.1/7.1-channel audio
    *   Audio Noise Guard
    *   High-End Audio Capacitors
*   **LAN:**
    *   Realtek® GbE LAN chip (1 Gbps/100 Mbps)
    *   LAN with Bandwidth Management
*   **Expansion Slots:**
    *   1 x PCI Express x16 slot, supporting PCIe 4.0 and running at x16 (from CPU)
    *   1 x PCI Express x1 slot, supporting PCIe 3.0 and running at x1 (from Chipset)
*   **Storage Interface:**
    *   1 x M.2 connector (Socket 3, M key, type 2280/2260 PCIe 3.0 x4/x2 SSD support)
    *   4 x SATA 6Gb/s connectors
*   **USB Ports:**
    *   **Chipset:**
        *   4 x USB 3.2 Gen 1 ports (2 ports on the back panel, 2 ports available through the internal USB header)
        *   4 x USB 2.0/1.1 ports on the back panel
*   **Internal I/O Connectors:**
    *   1 x 24-pin ATX main power connector
    *   1 x 8-pin ATX 12V power connector
    *   CPU fan header, system fan headers
    *   Front panel header
    *   Front panel audio header
    *   Speaker header
    *   Clear CMOS jumper
    *   Trusted Platform Module (TPM) header
*   **Unique Features:**
    *   6+1+1 Phases Hybrid Power Design (Low RDS(on) MOSFETs)
    *   Solid capacitors
    *   Smart Fan 6 (Multiple Temperature Sensors, Hybrid Fan Headers, FAN STOP)
    *   Anti-Sulfur Resistors Design
    *   GIGABYTE APP Center
    *   Q-Flash Plus
    *   Overvoltage Protection, Electrostatic Protection
