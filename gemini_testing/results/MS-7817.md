# Query: MS-7817

The MS-7817 refers to a series of MSI motherboards, including models such as the MSI B85M-E33, H87M-E33, and H81M-E33/E34. These motherboards are designed to support 4th Generation Intel Core processors with an LGA 1150 socket.

### Specifications for MSI MS-7817 (various models):

**Processor:**
*   **Socket:** LGA 1150
*   **Supported CPUs:** 4th Generation Intel Core i7 / i5 / i3, Pentium, Celeron Processors (Haswell)

**Chipset:**
*   Intel B85 Express Chipset (for B85M-E33 variant)
*   Intel H81 Chipset (for H81M-E33/E34 variant)
*   Intel H87 Chipset (for H87M-E33 variant)
*   Lynx Point PCH

**Memory:**
*   **Type:** DDR3 DIMM
*   **Slots:** 2 DIMM slots
*   **Maximum Installed Memory:** Up to 16 GB (for H81M-E33/E34), up to 32 GB (general MS-7817)
*   **Supported Frequencies:** 1066 MHz, 1333 MHz, 1600 MHz
*   **Architecture:** Supports Dual-Channel mode

**Expansion Slots:**
*   1 x PCI-E 3.0 x16 slot
*   1 or 2 x PCI-E x1 slots

**Storage:**
*   **SATA III (6Gb/s):** 2 ports (by Intel H81/B85/H87)
*   **SATA II (3Gb/s):** 2 ports (by Intel H81/B85/H87)

**Audio:**
*   **Controller:** Realtek ALC887 (or RTL892)
*   **Channels:** Flexible 8-channel audio with jack sensing
*   **Compliance:** Compliant with Azalia 1.0 Spec

**Networking:**
*   **Controller:** Gigabit Ethernet (Realtek RTL8111G)
*   **Speed:** 10/100/1000 Mbps

**USB:**
*   **USB 3.0:** 2 ports (front) by Intel H81/B85/H87, 4 ports (rear) by VIA VL805 (on H81M-E34)
*   **USB 2.0:** 2 connectors on-board, 2 ports on back panel (on H81M-E34)

**Internal Connectors (varies by specific model):**
*   USB 2.0 connectors
*   USB 3.0 connector
*   Chassis Intrusion connector
*   Front Panel Audio connector
*   Serial port connector
*   TPM Module connector
*   CPU x 1 / System x 2 FAN connectors

**Back Panel I/O Ports (varies by specific model):**
*   1 x PS/2 keyboard port
*   1 x PS/2 mouse port
*   1 x VGA port
*   1 x DVI port
*   1 x HDMI port
*   1 x LAN (RJ45) port
*   3 x Flexible audio ports

**Form Factor:**
*   Micro-ATX (e.g., 22.6 cm x 17.3 cm for H81M-E34)

**Features on Focus (depending on model):**
*   Command Center
*   M-Flash
*   Military Class 4
*   OC Genie 4
*   SATA 6G
*   USB 3.0
