# Query: HVM domU Xen

HVM domU (Hardware Virtual Machine Domain Unprivileged) in Xen refers to a fully virtualized guest operating system that runs on the Xen hypervisor. It utilizes hardware-assisted virtualization features provided by the host CPU to run unmodified guest operating systems.

### Specifications of HVM domU Xen

Here are the key specifications and characteristics of an HVM domU in a Xen environment:

*   **Virtualization Type**: HVM domUs employ full virtualization, also known as hardware-assisted virtualization. This means the guest operating system runs as if it were on bare metal, without requiring any modifications to its kernel.
*   **Hardware Requirements**: To run HVM domUs, the host CPU and motherboard must support specific hardware virtualization extensions. These include:
    *   **Intel VT-x** (Virtualization Technology) or **AMD-V** (AMD Virtualization) for CPU virtualization.
    *   **IOMMU** (Input/Output Memory Management Unit), such as Intel VT-d, needs to be enabled for I/O virtualization and device passthrough.
    *   **TXT** (Trusted Execution Technology) usually needs to be disabled in the BIOS.
*   **Guest Operating System Support**: HVM domUs can run a wide range of unmodified operating systems, including Windows, and various Linux distributions that do not have Xen-aware (paravirtualized) kernels. This is a primary advantage over paravirtualized (PV) guests, which require a specially modified kernel.
*   **Hardware Emulation**: Xen uses a modified version of QEMU (Quick EMUlator) to emulate standard PC hardware for HVM guests. This includes components like:
    *   BIOS
    *   IDE disk controllers
    *   VGA graphic adapters
    *   USB controllers
    *   Network adapters
    The QEMU device manager (`qemu-dm`) runs in Dom0 (the privileged management domain) to provide this emulation.
*   **Performance**: Pure HVM guests are generally slower than paravirtualized guests due to the overhead associated with hardware emulation. However, performance can be significantly improved by installing "paravirtualized drivers" (PV drivers) within the HVM guest, especially for critical I/O operations like disk and network access. This configuration is often referred to as PV-on-HVM or PVH.
*   **Configuration**: When creating an HVM domU, the Xen configuration file typically specifies `builder = 'hvm'`.
*   **Management and Console**: HVM domUs often use VNC for graphical console access.
*   **Relationship with Dom0**: Dom0 is the initial and privileged virtual machine that manages the Xen hypervisor and other guest domains (DomUs). Dom0 is typically a paravirtualized guest itself and is responsible for allocating resources and handling hardware emulation for HVM DomUs.
